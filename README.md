# AI-Automation-Projects

A collection of practical AI automation projects built with n8n, LLMs, APIs, and workflow integrations. Includes AI-powered email drafting and human approval workflows, chatbots with content guardrails, RAG-based customer support, image difference detection, and automated lead management. Each project demonstrates real-world AI applications, workflow design, and business process automation, with documentation and JSON workflow files for learning, testing, and reuse.
